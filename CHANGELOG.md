## [v0.1.0] - 2026-05-11

### Highlights

- Initial release of AIStandards.io website for AI standards listing, commentary, and implementation tracking
- TRON-inspired dark theme with semantic identity colors (cyan=human, orange=agent, purple=workload)
- Go CLI tooling for data validation, JSON schema generation, and Awesomely markdown export
